# MovieRecommendationSystem

Simple movie recommendation project. Contains a Python app and a Jupyter notebook.

Files of interest
- `app.py` — lightweight app (run with `python app.py`).
- `Movierecomnde.ipynb` — exploratory notebook.
- `tmdb_5000_movies.csv`, `tmdb_5000_credits.csv` — datasets used by the project.

Run

```
python app.py
# or open the notebook with Jupyter Lab/Notebook
```
